# Trading Games

A local-first practice suite for trading, probability, estimation, mental arithmetic, and market-making exercises.

## Development

```bash
npm install
npm run dev
```

Run checks with `npm run typecheck`, `npm test`, and `npm run build`.

## Current scope

The catalog covers the nine practice formats in the supplied materials. The first playable module is Math Challenge. The remaining modules are being added one by one only when their rules and settlement logic are sufficiently specified.
